# 头像展示接入（2026-09-03）

本轮接入范围：会话列表中的已有好友/群、通讯录好友/群，以及好友资料页。复用 fileId → 已鉴权下载接口 → 签名图片地址，不把私有存储改为公开桶。

统一 AppAvatar 为圆角方形。无头像、地址解析失败或图片加载失败时使用首字/群图标占位；首字按 Unicode 字符簇截取。父组件正常重绘不会重复解析地址，fileId 或解析服务变化时重新解析；旧请求晚到不能覆盖新头像。签名地址请求保留设备地址转换所需 headers，不附加业务访问令牌给对象存储。

## 后端授权补齐

原下载接口对 PRIVATE 一律只允许上传者，导致他人无法读取已绑定头像。现仅在下载 AVATAR 类型的 PRIVATE 文件时增加受限授权：

- 当前绑定到活跃用户的头像：已接受的好友关系，且双方没有拉黑关系。
- 当前绑定到活跃群的头像：请求者必须为该群活跃成员。
- 上传者仍可访问自己的文件；普通私有文件、无绑定/已替换的头像不因此向他人开放。
- 仅影响下载，不放宽转发、删除或上传授权。签名 URL 延续原有 10 分钟有效期；撤销关系不会立即使已签发链接失效，已下载图片也无法远程收回。

## 验证与边界

新增 Flutter 占位、失败回退、重复重绘、换头像/移除后的迟到回调和尺寸测试；后端测试覆盖好友访问、陌生人/拉黑/无绑定拒绝、群成员约束以及普通私有文件拒绝。

本轮不是完整 UI 改版，也不是头像全场景验收。聊天气泡、群成员、陌生人/非好友会话、群头像编辑入口以及刷新对方资料的实时通知仍需后续接入。会话列表已有接入代码，但本轮设备测试仅覆盖通讯录及好友资料页，不将其算作会话列表的设备验收。
