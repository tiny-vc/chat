# 登录页服务器设置

2026-09-03。本批补运行时服务器选择及相关隔离，不代表第一阶段所有发布/弱网工作完成。

## 使用

- 登录页显示当前 API 地址，提供“服务器设置”；登录请求期间不可进入，已登录时需先退出。
- 输入完整地址，点击“检测连接”，看到名称及协议版本后确认保存；修改输入会废弃旧检测结果。检测或保存失败不切换当前会话。
- 接受根地址及 `/api/v1` 后缀，规范化成 origin。禁止账号密码、查询参数、fragment 和其他路径；公网必须 HTTPS。HTTP 仅允许 localhost、IPv4 私网/回环和 IPv6 回环用于本地调试。
- `--dart-define=API_BASE_URL=...` 仍用于默认地址；已保存的选择优先，保存到系统安全存储。真机请使用可达的局域网 IP 或 HTTPS 域名。
- 用户只填写业务 API。WuKongIM 连接地址、LiveKit URL/临时 Token、文件签名 URL 继续由业务 API 返回。局域网部署同时配置 `docker-compose.lan.yml` 的对外地址，不能只修改 App 地址。

## 公开接口

`GET /api/v1/server-info` 无需登录，只返回 product=chat、apiVersion=1、name、registrationEnabled、uploadLimits。SERVER_NAME 支持环境配置；当前注册开放，未新增注册策略开关。上传上限与文件校验共用同一常量，避免文档值和真实限制分叉。

不返回数据库连接、管理端口、密钥或 ready 中的依赖细节。OpenAPI 已生成；App 在建立业务会话前使用独立 Dio 探测和严格协议校验，而非复用带认证的业务客户端。现有已生成业务客户端没有新增探测调用，已有业务接口契约不变。

探测不携带 Token、不跟随重定向、不跳过证书校验，设置连接/接收超时、12 秒总期限及 64 KiB 响应限制。业务 Dio 同样禁用自动重定向。检测成功只表明公开 API 格式兼容，不等同身份可信或 IM/通话/文件链路全部可用。

## 切换与隔离

- 以规范化 API origin 的 SHA-256 为存储命名空间；http/https、端口、不同域名彼此独立，不信任服务器自报的 ID 来合并数据。
- Token 安全存储、WuKongIM 数据库与 SQL 迁移标记、草稿及下载缓存均隔离。IM 网络 UID 不修改。文件 ID 哈希后用于缓存文件名，数据库身份拒绝路径字符，防止远端标识作为本地路径。
- 保存后销毁旧连接、监听和业务客户端，再建立新会话树；关闭旧数据库，清理内存图片缓存，SDK 初始化时清理不同身份的频道内存缓存。旧 IM 实例销毁后的凭据更新不再修改共享 SDK。
- 遵循“未上线，不需要旧版兼容”的要求：不自动迁移旧的未命名空间 Token/数据库/草稿/缓存。用户需重新登录；旧数据保留在原位置，不自动删除。新命名空间聊天记录依赖服务端可同步历史，不能把旧本地草稿说成自动恢复。

## 本轮边界

- 登录页运行时切换、公开 API 与基本安全隔离属于本批；尚未进行两套独立服务端、同 UID 的完整消息收发及文件实际下载交叉验收。
- 测试 origin 切换可以使用 localhost 与 127.0.0.1 两个地址连接同一本地 API；它验证界面/持久化闭环，不是两个独立部署的隔离验收。
- 生产 TLS、TURN/TLS、依赖安全升级、管理后台网页及真实音视频弱网仍需单独处理。
- 本地 API 镜像：chat-api:server-settings-local；Compose：docker-compose.yml + docker-compose.server-settings.yml。数据卷保留。
