# 双端联调（开发环境）

## 地址准备

手机与 Mac 接入同一可信 Wi-Fi，避免访客网络/AP 隔离。`LAN_HOST` 使用 Mac 的局域网 IPv4，不是手机 IP、localhost、Docker 容器 IP 或 10.0.2.2。

```sh
export LAN_HOST=你的Mac局域网IPv4
# 当前网络受限下的修复镜像；标准完整构建恢复后使用 chat-api:latest。
export CHAT_API_IMAGE=chat-api:expiry-local
docker compose -f docker-compose.yml -f docker-compose.lan.yml config --quiet
docker compose -f docker-compose.yml -f docker-compose.lan.yml up -d --no-build --no-deps --wait api livekit
```

此操作会重启 API 和 LiveKit，需确保没有正在测试的通话。保留现有数据库与文件，不删除数据卷。仅用于本地开发，不可用此 HTTP、开发密钥配置部署公网。

手机浏览器访问 `http://Mac局域网IPv4:3000/api/v1/health`。若无法访问，先检查网络隔离和防火墙，不要关闭整个系统防火墙。相关端口为 API 3000、消息 5100/5200、对象存储 9000、LiveKit 7880/7881 TCP 和 7882 UDP。

```sh
cd apps/flutter_chat
flutter run -d 设备ID --dart-define=API_BASE_URL=http://你的Mac局域网IPv4:3000
```

只修改 Flutter 的 API_BASE_URL 不够：服务器返回的 WuKongIM、LiveKit 和 S3 签名地址也必须可达。签名 URL 不应在真机端随意替换主机名，需由服务端按正确 S3_PUBLIC_ENDPOINT 重新签发。
