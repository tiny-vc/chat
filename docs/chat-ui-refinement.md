# 会话列表与输入区样式收敛（2026-09-03）

## 修改范围

- 会话行提取为 ConversationListTile，保持真实头像、置顶、摘要、时间、未读状态和原有点击/长按回调。统一 20px 外侧留白、48px 头像、16px 标题、13px 摘要；长名称/摘要单行省略，行高由内容撑开，时间区限制宽度。
- 点击反馈使用 Material / InkWell，置顶背景不遮挡水波反馈；滑动删除仍由原 Dismissible 处理。
- 输入框普通/聚焦圆角统一为 14px，普通状态无粗边框，聚焦时有清晰品牌色描边。保留文字、表情、附件和录音的现有行为。

## 媒体气泡与信息行

- 消息时间、发送状态和已读信息归入正文下面的 MessageMeta；不再用正文旁的独立窄列挤压媒体内容。使用 Wrap，在窄气泡或大字号下允许信息行换行。现有已读查询及发送状态判断不变。
- 文件展示提取为 FileMessageTile：图标、两行文件名、大小及打开提示分层。下载中禁用重复打开；未知进度显示“正在准备…”，不误显示为 0%。原下载服务、原生文件打开和错误反馈逻辑保留。
- 图片增加 ChatMediaFrame，按消息内宽高元数据计算容器比例（限 .65–1.8，无有效元数据时回退固定比例），等待、错误和加载完成共用容器尺寸。图片使用 contain 完整展示，网络图片失败增加重新获取签名地址的重试入口。
- 视频播放器和语音录制/播放逻辑未改动，但其外层消息信息行同样采用新布局。
