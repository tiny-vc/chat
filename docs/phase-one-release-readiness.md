# 第一阶段发布就绪清单

更新日期：2026-09-09。

本文用于判断当前版本能否进入真机验收或正式发布。历史联调过程及证据见
[第一阶段本机联调](local-phase-one-acceptance.md)，生产操作见
[生产部署](production-deployment.md)。

## 当前结论

- 服务端、Flutter App 和管理平台的第一阶段核心代码已达到**真机候选版本**状态。
- 用户端与管理端的第一阶段业务入口均有对应 API、成功反馈、失败恢复和状态刷新，
  代码与自动化层面已形成业务闭环；正式可用结论仍取决于真机矩阵。
- 自动化检查已全部通过，但这不等于真实音视频质量、系统后台行为和商店发布验收完成。
- 在两台真实设备完成下方必测矩阵前，不应标记为正式发布版本。

## 已通过的自动化门禁

- Flutter：`flutter analyze` 通过；`flutter test` 共 269 项通过。
- 服务端：`npm run lint`、`npm run build` 通过；27 个测试套件、169 项测试通过。
- 管理平台：lint、8 个测试文件/18 项测试及生产构建通过；路由已拆包，最大业务产物约 469 KB。
- 数据库：Prisma schema 校验通过；生产迁移镜像包含群资料、媒体引用和可靠删除迁移。
- 协议与部署：OpenAPI 关键路径、管理 CLI、群公告/群昵称迁移和生产预检项均已纳入 `scripts/verify-server.sh`。
- 部署：单机与外部 PostgreSQL/WuKongIM/LiveKit/S3 两套 Compose 均通过静态验证；
  外部模式将 API 与后台 worker 角色分离。

任何核心代码修改后，都应重新执行对应检查；跨层协议修改应执行全部检查。

## 真机发布阻断项

至少使用一台 Android 和一台 iPhone；通话与多端同步项目需要两台设备同时在线。

- 登录页修改、检测并持久化业务服务器地址；App 只配置业务 API，IM、LiveKit 和文件地址由服务端公开配置或业务接口返回。
- 注册、登录、退出、Token 刷新、密码错误、网络错误和权限拒绝后的恢复路径。
- 好友申请、同意后的状态即时更新；会话列表不得产生裸 UUID 或重复会话。
- 双向文字、表情、链接、回复、图片、视频、语音和文件发送、下载、失败重试及取消。
- 建群后直接进入群聊；邀请、申请审批、公告、群昵称、成员管理和部分邀请失败反馈。
- 双向语音和视频的真实收发、听筒/扬声器/蓝牙、前后摄像头、静音及挂断。
- Wi-Fi 与蜂窝切换、丢包、抖动、限速、短断网和长断网；验证音频优先降级、TCP/TURN 和 TURN/TLS。
- 来电前后台切换、App 被系统终止、系统电话或音频中断，以及相机/麦克风权限永久拒绝后的设置引导。
- 同一账号多设备登录、指定设备下线、会话状态同步及断线后的可靠补偿。
- 浅色/深色、窄屏、系统大字体、长名称、键盘遮挡和减少动态效果。
- 管理平台桌面端与移动窄屏的登录、导航、用户封禁、设备下线、群管理和审计记录。

发现阻断问题后应修复并重跑受影响场景，不能仅以单元测试替代真机复测。

## 部署验收

- `sh scripts/deploy-production.sh --check-only` 通过，部署后所有长期服务为 healthy；迁移和 MinIO 初始化容器正常以 0 退出。
- `/api/v1/health` 与 `/api/v1/ready` 正常，数据库、WuKongIM、LiveKit 和对象存储均就绪。
- WSS/HTTPS 证书链可信，证书自动续期已配置并进行一次演练。
- 外网仅开放文档规定的 HTTP(S)、WuKongIM、LiveKit 媒体和 TURN 端口；PostgreSQL、MinIO 与内部管理端口不公开。
- 首次部署仅执行一次 `bootstrap-admin-production.sh`；已有管理员的数据环境无需重复初始化。
- 数据库、对象存储和 WuKongIM 数据完成备份，并至少执行一次独立恢复验证。
- 验证磁盘容量、日志轮转、容器自动重启和服务器重启后的自动恢复。

## 正式分发前

- Android 使用正式签名生成 AAB/APK；iOS 使用正确 Bundle ID、证书和 provisioning profile，通过 TestFlight 或受控设备安装。
- 核对应用名称、图标、启动页、版本号、隐私政策、用户协议、权限用途说明和第三方开源许可。
- 不把测试账号、调试入口、开发服务器地址、明文密钥或生产证书打入客户端。
- 为生产 API 和管理平台保存可回滚的不可变镜像版本，并记录数据库迁移兼容边界。

## 第一阶段明确延期

- 离线系统推送；
- iOS CallKit、Android ConnectionService，以及 App 被系统彻底终止后的系统来电唤醒；
- 群语音和群视频；
- Prometheus；
- 基础设施自动故障转移和完整多节点高可用（分机部署及 API/worker 分离已支持）；
- 端到端加密。

这些延期项不阻止第一阶段真机验收，但产品页面和宣传材料不得暗示已经支持。
