# 通话信令与来电弹窗验收（2026-09-03）

## 修复

原 HomePage 只处理 invite，来电弹窗不会响应对方 cancel/miss/end，可能继续响铃并停留至本地超时；超时直接 pop 当前路由，也可能误关弹窗上方的其它页面。

抽取共用 showIncomingCallDialog：仅匹配当前 callId，收到结束信令立即关闭该弹窗，明确区分接听、拒绝、远端结束和本地超时。按持有的 DialogRoute 移除，避免弹出无关页面；完成时统一取消铃声、超时与订阅。HomePage 只在用户明确拒绝时调用 reject，不在远端取消后反向拒绝；try/finally 释放来电占用标记，同一 callId 的重复邀请不误回 busy。

4 项控件测试覆盖 cancel/miss/end、重复与无关结束信令、结束后新邀请、45 秒本地超时及上层无关页面保护。初始控件断言早于真实 zone 的订阅取消完成，现等待该异步清理，不删除结果断言。
